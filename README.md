# Enterprise LMS Helpdesk Agent
A helpdesk chatbot for a fictional company's (NorthPeak Technologies) employee learning portal. It answers common LMS questions from a knowledge base of 10 help articles (loaded as a PDF) and escalates unresolved issues to a form that captures the details a support team needs. Inspired by the responsibilities of an enterprise learning-platform support role. All data is fictional.

## Tools
Botpress, Google Forms, Google Sheets, Loom
Knowledge base: help-articles.pdf (10 help articles)

## Testing
20 test questions: 10 answerable, 2 reworded, 4 vague, 2 risky and 2 out of scope. All 20 were handled correctly in one test round. See test-results.pdf and the 06 screenshots.

## Release checklist
A reusable checklist template for testing the learning portal after every update (see release-checklist.pdf).

## Limits
Fictional data, English only, tickets are not created automatically yet.
